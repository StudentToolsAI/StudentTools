📐 Pythagorean Theorem Formula

a² + b² = c²

In a right triangle, a and b are the two shorter sides, while c is the hypotenuse, which is the longest side.

What is the Pythagorean Theorem?

The Pythagorean Theorem is a mathematical rule used to find the length of a missing side in a right-angled triangle.

The theorem states that the square of the hypotenuse is equal to the sum of the squares of the other two sides.

Example

Suppose a right triangle has side A = 3 and side B = 4.

Using the formula:

c = √(3² + 4²)

c = √(9 + 16)

c = √25 = 5

Therefore, the hypotenuse is 5 units.

💡 Quick Tips

  • The hypotenuse is always the longest side.
  • The Pythagorean Theorem works only for right triangles.
  • Make sure all side values are positive numbers.
  • The result uses the same unit as the values you enter.
