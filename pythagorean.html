📚 Pythagorean Theorem

The Pythagorean theorem is used to find the missing side of a right-angled triangle.

a² + b² = c²

What do the letters mean?

a and b are the two shorter sides of the triangle.

c is the hypotenuse, which is always the longest side.

Example

If Side A = 3 and Side B = 4:

c = √(3² + 4²)
c = √25
c = 5

Therefore, the hypotenuse is 5 units.
